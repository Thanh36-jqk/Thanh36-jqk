### &nbsp;&nbsp;`~` &nbsp;Flagship — NexusSec

**Enterprise-grade Pentest-as-a-Service platform.**
Golang microservices behind a RabbitMQ message broker, Docker-isolated execution for untrusted
scan workloads, and a Next.js control plane streaming live results over WebSockets.

```
  client ──▶ Next.js API ──▶ RabbitMQ ──▶ [ worker pool ]
                   ▲                            │
                   └────── WebSocket ◀──── Docker-isolated scans
```
